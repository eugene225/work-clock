🕒 근무시간 계산기

✨ 새로운 기능: 자동 페이지 이동

어느 페이지에서든 북마크를 클릭하면:

  1. Workplace 페이지가 아니면 확인 창이 나타납니다
  2. "확인"을 누르면 자동으로 Workplace 페이지로 이동
  3. Workplace 페이지에 있으면 바로 근무 시간 계산!

📊 계산되는 정보

  • 총 근무일: 이번 달 전체 근무일 (dayTpCd == 'WORK')
  • 오늘까지 근무한 시간: 실제로 일한 시간
  • 앞으로 근무해야 하는 시간: 총 근무일 × 8h - 근무 시간
  • 현재 초과/부족: 오늘 기준 초과/부족 시간
  • 오늘 포함 여부: 오늘 근무시간 자동 감지

⌨️ Shift 키로 empId 변경

Shift 키를 누른 채로 북마크를 클릭하면 empId를 다시 입력할 수 있습니다.

💡 다른 페이지에서 Shift+클릭해도 상태가 유지됩니다!

🚀 사용 방법

  1. 위의 버튼을 북마크바로 드래그
  2. 어느 페이지에서든 북마크 클릭
  3. Workplace 페이지가 아니면 자동 이동
  4. 근무 시간 계산 결과 확인!
